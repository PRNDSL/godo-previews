ことのはし英会話 / クラス

クラス

4つとも大人だけで、多くて5人です。迷ったら体験で1回入ってから決めてください。

どこに入るか

トップの3つの問いに、「読んで話す」を足した分け方です。合わなければ、翌月から別のクラスに替えられます。

  • はじめて単語は浮かぶけれど、文にならない人
  • 旅行と日常短いやり取りはできるが、聞き返されると詰まる人
  • 仕事で使う会議や電話で、言いたいことを間に合わせたい人
  • 読んで話す英語の本を読んで、その話を英語でしたい人

はじめて

人数
4人まで
長さ
60分
曜日
月曜 10:30〜11:30
木曜 19:30〜20:30
先生
柚木

授業でよく出る一文Sorry, could you write it down for me?

進め方

  1. 最初の10分は、先週の文を一人ずつ声に出します。
  2. 新しい文を5つ。日本語で意味を確かめてから、口の形をまねます。
  3. 2人1組で、その文を入れた短いやり取りをします。
  4. 最後に、家で言ってみる文を3つノートに書いて帰ります。

向く人

  • 中学で英語を習ったが、長いあいだ使っていない
  • 英語で話しかけられると、黙ってしまう
  • 文法の説明より、まず言えるようになりたい

海外の取引先からの電話を、いつも同僚に回していた人。

旅行と日常

人数
5人まで
長さ

火曜 10:30〜11:30
金曜 19:30〜20:30
土曜 10:00〜11:00
先生
ヘイデン

授業でよく出る一文Is there a pharmacy near here?

進め方

  1. その日の場面を1つ決めます。ホテル、駅、薬局、レストランなど。
  2. ヘイデンが店の人の役をして、一人ずつやり取りをします。
  3. うまく言えなかった所を、全員で言い直します。
  4. 最後の10分は、その週にあった事を英語で一言ずつ話します。

向く人

  • 旅行先で、注文や道を自分で聞きたい
  • 簡単なやり取りはできるが、聞き返されると詰まる
  • 英語で育った人の話す速さに慣れたい

次の旅行の行き先を決めてから、練習したい場面を先生に頼んでくる人。

仕事で使う

人数
4人まで
長さ
60分
曜日
火曜 20:00〜21:00
土曜 13:30〜14:30
先生
柚木とヘイデン(2人で入ります)

授業でよく出る一文Could we go back to the second point?

進め方

  1. その週に、仕事で言えなかった一言を持ってきます。
  2. 柚木が日本語で場面を聞いて、言い方をいくつか出します。
  3. ヘイデンを相手に、会議や電話の形で言ってみます。
  4. メールの文は、口で言える長さに直します。

仕事の資料を持ってくる時は、会社の名前や数字を消してからにしてください。

向く人

  • 会議で言いたいことがあるのに、間に合わない
  • メールは書けるが、電話や画面越しの会議が苦手
  • 自分の仕事の言葉で練習したい

読んで話す

人数
5人まで
長さ
75分
曜日
水曜 14:00〜15:15
土曜 15:30〜16:45
先生
ヘイデン

授業でよく出る一文What would you have done in her place?

進め方

  1. 1冊の本を、毎週10ページほど家で読んできます。
  2. 最初の15分は、読んだ所を自分の言葉でまとめて話します。
  3. ヘイデンの問いに答えながら、登場人物や書き手の考えを話し合います。
  4. 分からなかった単語は、最後に全員で確かめます。

本はクラスで話し合って決め、各自で買ってもらいます。1冊1,000円から2,000円ほどが目安です。

向く人

  • 英語の本を一人で読んでいるが、話す相手がいない
  • 自分の考えを、少し長い英語で言いたい
  • 読むのが好き

一人で読み終えた本の話を、誰かとしたくて来た人。
