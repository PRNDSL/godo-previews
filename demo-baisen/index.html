朴葉坂の豆売り焙煎所 うすけむり

週に4日だけ店を開けて、焼いた豆を量り売りしています。飲む席はありません。豆を持って帰って、家で淹れてください。

生豆浅煎り中浅中煎り中深深煎り

焙煎度で選ぶ

つまみを動かすと、いま棚にある8種のうち、その焙煎度の豆だけが出ます。

いま棚にある8種です。

  • エチオピアの水洗い950円

    浅煎り / 紅茶、レモンの皮、白い花

  • ケニアの水洗い1,050円

    浅煎り / カシス、トマト、はっきりした酸

  • ルワンダの水洗い900円

    中浅煎り / 赤いりんご、はちみつ

  • コロンビアの水洗い800円

    中煎り / ミルクチョコ、くるみ

  • ブラジルの天日干し700円

    中煎り / ピーナッツ、ココア、甘い後味

  • グアテマラの水洗い850円

    中深煎り / 黒糖、カカオ、少しスパイス

  • インドネシアの半乾き脱穀850円

    深煎り / 杉の葉、ダークチョコ、重い苦み

  • けむりブレンド750円

    深煎り / 焦がしたキャラメル、長く残る苦み

値段は100gの税込です。仕入れで変わることがあるので目安として見てください。
